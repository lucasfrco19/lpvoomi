# Voomi Landing Page

Landing page responsiva da Voomi, construída com Next.js, React, TypeScript e GSAP.

## Requisitos

- Node.js 22
- pnpm 10

## Desenvolvimento

```bash
pnpm install
pnpm dev
```

A aplicação ficará disponível em `http://localhost:3000`.

## Validação

```bash
pnpm lint
pnpm build
```

## Estrutura principal

- `app/page.tsx`: conteúdo e interações da landing page
- `app/globals.css`: estilos e responsividade
- `public/assets`: imagens, vídeos e pôsteres usados na página
